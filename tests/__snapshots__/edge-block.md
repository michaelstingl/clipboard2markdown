Block-Level Edge Cases
======================

### Blockquote mit mehreren Absätzen

> Erster Absatz im Zitat mit Umlauten: äöüß.
>
> Zweiter Absatz im selben Zitat.

### Code-Block mit Sprache

```python
def hello(name: str) -> None:
    print(f"Hello, {name}!")
```

### Code-Block ohne Sprache

```
plain code
no language hint
```
